# Auto Check – GitHub / Android

Diese Version ist als **mobile Web-App / PWA** gebaut und für Android-Handys optimiert.

## Enthalten
- Bild 1 als App-/Browser-Icon
- Bild 2 als Hauptbild
- Bild 3 als Logo-Overlay; das Logo fährt von oben ein
- Logo-Animation: **2,5 Sekunden**
- 6 Menü-Karten wie in Bild 4
- Buttons fahren von links/rechts ein: **2,5 Sekunden**
- responsive Layout für Android
- PWA-Manifest + Service Worker

## GitHub
Die ZIP-Datei enthält bereits die fertige Ordnerstruktur. Nach dem Hochladen müssen `index.html`, `styles.css`, `app.js`, `manifest.webmanifest`, `sw.js` und der Ordner `assets/` zusammen bleiben.

Für GitHub Pages:
1. Repository öffnen.
2. Dateien aus dieser ZIP ins Repository übernehmen.
3. In **Settings → Pages** als Quelle den gewünschten Branch und `/ (root)` wählen.
4. Die erzeugte Pages-Adresse auf dem Android-Handy öffnen.
5. Im Browser **„Zum Startbildschirm hinzufügen“** / **„App installieren“** wählen.

Die sechs Buttons zeigen aktuell einen kleinen Hinweis an. Die eigentlichen Unterseiten/Funktionen können danach an die jeweiligen Bereiche angebunden werden.
